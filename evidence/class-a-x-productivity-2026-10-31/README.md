# Exact X-descendant audit and local ladder receipts

Scope: 22 complete minus-class-A graphs (the 16 original members and six
explicit controls), plus a local productive family over an unbounded integer
domain. The universal productivity of Reach(X) is **not** established.
The mathematical derivation and all hypotheses are in
`docs/class-a-x-productivity-2026-10-31.md`.

## Executed evidence

* `finite-certificates.json`: inspectable compact JSON containing every
  full typed vertex and three indexed rank forests per graph. The graph
  SHA-256 pins all literal indexed edges as generated by the replay.
  All 16,132 vertices and 190,966 indexed edges are in completed graphs;
  a cap raises instead of returning a partial verdict.
* `native-graphs.log`: canonical Mojo finite summaries for the same 22
  members, using the repository's locked Mojo 1.1.0.dev2026090805 toolchain.
  Both the graph and the ladder native regressions passed locally.
* `native-oracle-comparison.json`: the native test was run with
  `--emit-indexed`; **every** native full label and indexed edge was compared
  with independent literal-word/Fraction enumeration, not merely counts.
  All graphs and their SCC/reachability statistics agree. The temporary
  4,952,840-byte native emission is reproducible from the pinned sources;
  its SHA-256 and canonical per-member labelled graph digests are recorded.
* `native-ladder.log`: 538 oriented native member paths on k,t=0..8,
  excluding the two explicitly refused faces. Path caps, wrong endpoint
  types and out-of-domain indices are refused.
* `python-tests.log`: all **eight** tests pass, including 824 oriented
  ladder paths / 18,456 selected edges over 118 admissible specimens,
  full graph/forest replay, polynomial mutations and negative controls.
* `symbolic.json`: sixteen genuinely directed base/transfer polynomial
  edge identities over Z[k,t,m], three cubic-root remainder identities,
  both shift identities and the written ordinal slack identities pass.
  SymPy 1.14.0 is used for exact polynomials only. Strict positivity and
  domain guards are justified by the written argument, not a sample fit.
* `dependency-status.json`: fresh PR/head/CI inspection. None of
  #428/#430/#431/#432/#433 is merged or has demonstrated exact-head hosted
  acceptance. This PR imports no files from those unaccepted certificates.
