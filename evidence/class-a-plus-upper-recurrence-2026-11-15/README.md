## Mathematical controls

Direct absolute contraction is false for `J<=4`:
`1-A-C=((J-4)beta-4)/(beta(beta+1))<0`.
The finite sheared box replaces that failed mechanism. Periodicity is
derived from finitely many integer pairs. For `J<=4`, the strict cyclic
energy argument forces a constant parity-transformed tail; for `J>=5`,
the established maximum-predecessor argument gives constancy. A genuine nonzero
tail is not a zero hit; the alternative occurrence exit is required.

Scalar constancy does not immediately identify the complete packet.
For `J=1`, `yy(1,2,-5)` requires its literal `(1,1)` step to
`yy(-1,-3,6)=-W_1`. Native and independent controls reject a zero-length
central phase for that source. The retired `JH=4` occurrence `n+2` is
still LAST `c`; its false RUN-`y` relabeling remains rejected.

For `3<=JH<=n-1`, the all-height exit starts

```text
yy(H,3H,-6H)
  --(0,JH-2)--> xy(1-H,-3H,6H-3)
  --(J(H-1)+4,1)--> yy(H-1,3(H-1),-6(H-1)).
```

This genuine height descent terminates at zero or one of the already
accepted three-edge bases. Reversal swaps the two original indices and
negates the entire offset. It does not merely change the height sign.
