### 2.1 Setting and the normalization

Alphabet `{0, 1, 2}`. A balanced pair `(u, v)` has `|u| = |v| = n` and
`p(u) = p(v)`; it is irreducible if `p(u[0, t)) ≠ p(v[0, t))` for
`0 < t < n`, i.e. the two lattice paths `γ_u`, `γ_v` share no vertex inside.
`K₂(u, v) = Σ_{i<j} K_ij e_i∧e_j` with `K_ij = N_ij(u) − N_ij(v)` (scattered
subword counts), and `k(u, v) = ⋆K₂ = (K₁₂, −K₀₂, K₀₁)`. `M[i][j]` is the
number of letters `i` in `σ(j)`. The children of `(u, v)` are the irreducible
blocks of `(σu, σv)`, top from `σu`; `N[S][T]` is the multiplicity of `S`
among the children of `T`. A strict system is a finite nonempty child-closed
set of irreducible noncoincident pairs.

**Lemma A (loop area; corrected normalization).**
(i) Let `Γ` be the closed loop "`γ_u`, then `γ_v` reversed". Then
`½ Σ_i q_i∧q_{i+1} = K₂(u, v)` over the vertices `q_i` of `Γ`.
(ii) Let `r_β > 0` be the right Perron vector and
`ω_s := det(r_β, ·, ·)`. Then `ω_s` vanishes on `r_β`, so it is an area form
on `E^s` (projection `π` along `E^u = ℝr_β`), and
`A^s(u, v) := ω_s(K₂(u, v)) = r_β·k(u, v)` is the `ω_s`-signed area of the
projected loop `π(Γ)`.
(iii) `ω_s` is the left eigen-row of `Λ²M` for `α₂α₃ = det M/β`.

*Proof.* (i) `Σ_t γ_w(t)∧γ_w(t+1) = Σ_{s<t} e_{w_s}∧e_{w_t} = area(w)`; the
reversed bottom path contributes `−area(v)`, and balance gives
`N_ij + N_ji = p_i p_j` on both tracks, so `area(u) − area(v) = 2K₂`.
(ii) `ω_s(x, y) = ω_s(πx, πy)` and the shoelace formula. (iii)
`(Mx)×(My) = cof(M)(x×y)` with `cof(M) = det(M)·M^{−T}`, so
`r_β·cof(M)k = det(M)(M^{−1}r_β)·k = (det M/β) r_β·k`. ∎

*Correction to the brief's wording.* For irreducible `χ_M` the eigenvalues
`βα₂`, `βα₃`, `α₂α₃` of `Λ²M` are distinct, so each eigen-row is unique up to
a scalar and `η₂∧η₃ = c·ω_s` with `c ≠ 0`; `c` is real for real conjugates
and purely imaginary for a complex pair (`η∧η̄ = −2i·Re η∧Im η`). So the
pairing with `η₂∧η₃` has no canonical sign; the canonical real form is
`A^s`. Relabelling the letters by a permutation `π` multiplies `A^s` by
`sgn(π)`, so a sign law must be stated equivariantly. For a real conjugate
`α_k`, `ω_k = det(r_{α_k}, ·, ·)` is the left eigen-row for `βα_j`
(`j ≠ k`), the area of the projection along `r_{α_k}` onto
`span(r_β, r_{α_j})`; there both projected paths are graphs over the
`ℓ`-axis but can still cross without sharing a vertex, and `r_{α_k}` has no
canonical sign, so only sign-constancy statements are normalization-free.
For a complex pair `βα₂`, `βα₃` are not real and no sign law is propagated.

### 2.2 What holds (single prover, no verifier)

**Lemma B (eigen-relation; no closure or strictness needed).** For every
balanced `(u, v)`: `K₂(σu, σv) = Λ²M·K₂(u, v) = Σ_B K₂(B)` over the
irreducible blocks `B` of `(σu, σv)`; coincident blocks contribute `0`. Hence
`Σ_B ψ_λ(K₂(B)) = λ·ψ_λ(K₂(u, v))` for each eigen-row `ψ_λ`, and `A N = λA`
on every child-closed set, coincidences admitted. If `N R = βR` then
`A·R = 0`.
*Proof.* Lemma 0 at `r = 2` (imported); concatenation
`area(xy) = area(x) + area(y) + p(x)∧p(y)`, whose cross terms cancel because
the blocks are balanced; substitution
`area(σw) = Λ²M·area(w) + C_σ p(w)` (mid-area note §2), whose last term is
equal on both tracks. `(λ − β) A·R = 0` with `λ ≠ β`. ∎

**Lemma C (nonvanishing; this is where irreducibility enters).** Let `χ_M` be
irreducible and `k ∈ ℚ³`. If `r_μ·k = 0` for one root `μ`, then `k = 0`. So
`A_λ(T) ≠ 0` iff `K₂(T) ≠ 0`, and with R1(b) a system with `K₂ ≢ 0` has every
`A_λ ≢ 0`.
*Proof.* Write `r_μ = (p_i(μ))` with `p_i` a column of `adj(tI − M)` nonzero
modulo `χ`. `r_μ·k = 0` makes `Σ k_i p_i` divisible by `χ`, so
`r_{μ′}·k = 0` for all three roots, and these right eigenvectors form a
basis. ∎
It fails on reducible input: on C-D1 the `μ = 1` functional vanishes on
`(0112, 2011)` and one more state, both with `K₂ ≠ 0`; the `λ = −β`
functional of `1/012/101` vanishes on `(12, 21)` and `(21, 12)`; `A^s`
vanishes on 12 of the 20 states of `01/2/120`.

**Lemma L2 (length two).** `K₂(ab, ba) = e_a∧e_b`, so
`A^s(ab, ba) = det(r_β, e_a, e_b) = ±r_c` with `c` the third letter, positive
iff `b ≡ a + 1 (mod 3)`. Hence for each letter `c` the pairs `(ca, ac)` and
`(cb, bc)` both have `c` first on top and have opposite signs of `A^s`.

**Proposition D (Perron–Frobenius obstruction).** Let `σ` be primitive with
Perron root `β`, `C` a strict system with `N` irreducible, `ρ(N) = β` (R0),
`λ` real with `|λ| < β`, `A ≢ 0` with `A N = λA`, and `s: C → {±1}` with
`x := sA ≥ 0`. Then some child edge `T → S` has `s(S) = s(T)` and some has
`s(S) = −s(T)`. If moreover `x > 0`: `λ < 0` forces every state to have an
`s`-reversing child, and `λ > 0` forces every state to have an
`s`-preserving child.
*Proof.* Split `N = P + Q` into `s`-preserving and `s`-reversing
occurrences; then `x(P − Q) = λx`. If `Q = 0`, `xN = λx` with `x ≥ 0`,
`x ≠ 0`, so `λ = ρ(N) = β` by Perron–Frobenius; if `P = 0`, `−λ = β`. If
`x > 0`: `2xQ = xN − λx`, `2xP = xN + λx`, and `(xN)_T > 0` because every
state has a child. ∎
*Application to PIP3.* Each real `λ ∈ {α₂α₃, βα₂, βα₃}` has
`0 < |λ| < β` (Pisot and `det M ≠ 0`). So on a strongly connected strict
system with `K₂ ≢ 0` no `A_λ` has constant sign, for every determinant; a
sign law relative to an orientation `s` says exactly that `x = sA` is a
positive left eigenvector of the signed matrix `S_s = P − Q` at `λ`, and `s`
can be neither a gauge nor an anti-gauge orientation (orientation-spectrum
note Proposition 3). In particular a flat system with the hub on top in every
state would contradict any hub-relative positivity law; but Perron–Frobenius
already forbids a constant sign there, and `det M < 0` adds only the
combinatorial clause "every state has a reversing child". *At `cr = 2`*
(Theorem W): for a swap-odd `s`, `S_s` is `N₋` in the basis `T⁺ − JT⁺`;
`S_s = ±N₊` would give `ρ(N₋) = β`, against W3. So the conclusion of
Proposition D already holds there without any positivity.

**Proposition 2L (two-letter calibration).** On `{0, 1}` let `(u, v)` be
irreducible noncoincident with `u₀ = 0` and
`d_t = #₀(u[0, t)) − #₀(v[0, t))`. Then `d_t ≥ 1` for `0 < t < n`
(`d₁ = 1`, `d_t ≠ 0`, steps of size at most 1), and
`N₀₁(w) = Σ_s [w_s = 0](n − 1 − s) − C(#₀, 2)` gives
`K₂ = Σ_{t=1}^{n−1} d_t ≥ n − 1 > 0`. So positivity holds on two letters.
Coherence fails: `σ = 100/01` is primitive and unit Pisot
(`χ = t² − 3t + 1`); it sends `(01, 10)` to `(10001, 01100)`, whose children
are `(10, 01)` with `K₂ = −1` and `(001, 100)` with `K₂ = +2`; the sum is
`1 = det M·K₂(01, 10)`. So positivity with the eigen-relation does not run
Proposition D even on two letters, and the non-spectral two-letter proof
that the round-3 note §5.6 points to rests on more than this sign.

### 2.5 The first failed premise

The premise "a degree-two area functional has a sign law on the states of a
strict system, derived from literal irreducibility of each pair" fails
twice. On literal pairs every tested law fails at length 2 or 3 (§2.3), and
on a strongly connected strict system Proposition D forbids a constant sign.

### 3.1 Setting

`σ ∈ PIP3` at any determinant; `Ω = Ω_σ`, `Φ` the inflation (a
homeomorphism), `h = h_φ: Ω → 𝕋_A` with `h∘Φ = A∘h` and
`h(T − t) = h(T) + (β^k t r)_k` (round-3 note §4.1, (R1)). `Z` is a strict
component: (Z1)–(Z4) of Lemma 8 of the (F)-class note at every determinant
(rank-two note §6.1), with (Z4) read as `h(T) = h(T′)` (round-3 note §4.2).
`P(T) = {T′ : (T, T′) ∈ Z}` is the set of partners of `T`, finite because it
lies in a fibre of `h` (BBK Thm 4.2); `π₁(T, T′) = T` is onto because `Ω` is
minimal. `F₀ = h⁻¹(0)` is the zero fibre: finite, `Φ`-invariant, its members
`Φ`-periodic, and every `Φ`-periodic tiling with a vertex at `0` lies in it
((R4)). Two tilings agree on `[x, ∞)` if the tiles meeting `(x, ∞)` coincide;
`T ∼_R S` if they agree on some `[x, ∞)`, and `∼_L` symmetrically.

`g` and `g_R` are the first- and last-letter maps. `ER` is the bipartite
graph on `{b⁺} ⊔ {a⁻}` with an edge `b.a` for each legal `ba` with
`b ∈ Per(g_R)`, `a ∈ Per(g)` (the eventual range of BD08's map). For
`(b, a) ∈ ER`, `T_(b,a) = lim σ^{Qn}(b).σ^{Qn}(a)` is the *vertex-type*
member of `F₀` with seam `(b, a)` at `0`. For irreducible `χ_M`, `ER` is
connected and `dim H¹(Ω; ℚ) = 3 + l` with `l` the cycle rank of `ER` (BD08
Thm 4 with Lemma 7(2) of the (F)-class note), so **`dim H¹ = 3 ⟺ ER` is a
tree**.

The *zero-fibre class graph* `ℬ` has as vertices the `∼_R`-classes and the
`∼_L`-classes of `F₀` and as edges the members of `F₀` (each joins its
`R`-class and its `L`-class). `𝒦` is the component of `ℬ` that contains the
vertex-type members (one component: `T_(b,a)` and `T_(c,a)` agree on

**(NM_V)**: a member of `F₀` that is right-asymptotic (resp. left-asymptotic)
to a vertex-type member is itself vertex-type with the same right (resp.
left) letter.

### 3.2 Statements (binding form)

1. **Lemma C (any `dim H¹`).** `π₁` is a covering ⟺ `π₁` is locally
   injective ⟺ no tiling has two distinct partners that agree on a
   half-line. By minimality, either `π₁` is a covering of constant degree,
   or it is locally injective at no point of `Z`.
2. **Lemma A.** Let `T ≠ S` be `Φ^Q`-fixed and right-asymptotic. They branch
   at a common vertex `x* ≥ 0`, and `x* = 0` whenever the last letters of
   `σ^Q` of the two tiles ending at `x*` differ; this always holds when
   `g_R` is injective. The mirror statement holds with `g`.
   *Consequence:* if `g_R` is injective, no interior member of `F₀` is
   right-asymptotic to another member; if `g` is injective, no interior
   member is left-asymptotic to another member.
3. **Lemma L.** If `π₁` is a covering, then along any asymptotic pair
   `T, S` the partners correspond bijectively, each partner of `T` going to
   the partner of `S` asymptotic to it.
4. **Theorem NC′ (any determinant, any `dim H¹`).** If `π₁` is a covering,
   then `𝒦` contains a cycle. Equivalently, there is an asymptotic cycle in
   the sense of Barge 2015 among members of `F₀` in that component. More
   precisely, `𝒦` carries a side-preserving graph endomorphism with no fixed
   vertex.
5. **Corollary NC.** Assume `dim H¹ = 3` (`ER` is a tree, at every
   determinant) and (NM_V), in particular `g` and `g_R` both injective. Then
   `π₁` is not a covering; `π₁` is locally injective at no point; some tiling
   has two distinct partners that agree on a half-line. (NM_V) can be
   replaced by "`𝒦` is a tree". The class with `g` and `g_R` both injective
   is empty in the corpus and nonempty beyond it: 24 PIP3 specimens with
   images of length at most 4 and `l = 0` have `g`, `g_R` both permutations,
   e.g. `010/102/2001` (scratch, recomputed by the verifier).
6. **Proposition F and Corollary P (`dim H¹ = 3`).** If `π₁` is a `k`-fold
   covering, then `k·𝔉(Z) ⊂ E = ⋃_n β^{−n}(ℤr₀ + ℤr₁ + ℤr₂)` (`𝔉(Z)` the
   frequencies of collared patches of `Z`, in particular `k·x_B ∈ E` for the
   frequency `x_B` of each bigon `B`); `2 ≤ k ≤ cr − 1`; and for a
   swap-closed `Z`, `k` is even unless `det M` is even. This is a complete
   proof of the round-1 covering-degree parity draft (closure-attempt §11),
   not a sharpening of it.

*What follows for strict systems.* On the class where `𝒦` is a tree, at
`dim H¹ = 3`: `π₁` is injective at no point (Fork) and locally injective at
no point (NC); a partner is not locally determined by the top track, since
some tiling has two distinct strict partners that eventually coincide; the
transfer or deck-group route of round 1 is unavailable there, and the parity

### 3.3 Proofs

**Facts used.** (R3): for fibre-mates, two tiles of the same type whose left
ends are less than `δ₀` apart are the same tile. (R4) as in §3.1. (Z1)–(Z4).
(E1) `T ∼_R S ⇒ h(T) = h(S)`: `d(T − t, S − t) → 0`, `h` is uniformly
continuous and `h(T − t) − h(S − t) = h(T) − h(S)` for every `t`.

*Step 0 (vertex-type members).* Let `T ∈ F₀` have a vertex at `0` with seam
`(b, a)`, and `Q₀` a period of `Φ` on `F₀`. Then `σ^{Q₀}(b)` ends with `b`,
`σ^{Q₀}(a)` starts with `a`, `ba` is legal, so `(b, a) ∈ ER`, and
`T = T_(b,a)`. Conversely each `T_(b,a)` is legal, `Φ`-periodic, with a
vertex at `0`, so it lies in `F₀` by (R4).

*Lemma A.* Let `x* = inf{x : T, S agree on [x, ∞)}`, finite since `T ≠ S`.
If `x*` lay inside a tile `τ` of `T`, then `τ` meets `(x*, ∞)`, so `τ ∈ S`
and the agreement would extend left of `x*`; so `x*` is a vertex of both,
and the tiles `t`, `s` ending there differ. Inflation sends "agree on
`[x, ∞)`" to "agree on `[β^Q x, ∞)`" and `Φ^Q` fixes `T`, `S`, so
`x* ≤ β^Q x*`, i.e. `x* ≥ 0`. If the last letters of `σ^Q(t)`, `σ^Q(s)`
differ, `T` and `S` differ at the tiles ending at `β^Q x*`, so
`x* = β^Q x*` and `x* = 0`. ∎

*Lemma C.* (a) *Locally injective ⇒ covering.* `c(T) = |P(T)|` is finite;
if `T_j → T` with `c(T_j) ≥ m`, limits of `m` distinct points over each `T_j`
are distinct by local injectivity, so `{c ≥ m}` is closed; it is
flow-invariant, hence `∅` or `Ω`, and `c ≡ k`. For the fibre `z₁, …, z_k`
over `T` choose disjoint open `U_i ∋ z_i` with closures on which `π₁` is
injective; `V = Ω ∖ π₁(Z ∖ ∪U_i)` is open (`π₁` is closed), every point of
`V` has one preimage in each `U_i`, and each `π₁|cl(U_i)` is a homeomorphism
onto its image, so `V` is evenly covered. (b) *Covering ⇒ no asymptotic
partners.* If `T′ ≠ T″ ∈ P(T)` with `T′ ∼_R T″`, the points
`(T − t, T′ − t) ≠ (T − t, T″ − t)` lie over one tiling and their distance
tends to `0`; a limit point is a point where `π₁` is not locally injective.
(c) *No asymptotic partners ⇒ locally injective.* If local injectivity fails
at `(T, T′)`, there are `(S_j, S_j′) ≠ (S_j, S_j″)` converging to it;
`S_j′`, `S_j″` are fibre-mates by (Z4) and agree with `T′` on
`[−R_j, R_j]` up to `ε_j → 0`, so by (R3) they agree exactly on
`[−R_j + 1, R_j − 1]`. Translate to the first common vertex where they
differ and pass to a limit in the closed set `Z`: two partners of one tiling
that agree exactly on `(−∞, 0]` (by (R3)) and differ at `0`. (d) The set of
points where `π₁` is not locally injective is closed and flow-invariant, and
`Z` is minimal (Z1). ∎

*Lemma L.* By compactness there are `δ, η > 0` such that distinct points of
one fibre are at least `η` apart and each `y` with `d(π₁z, y) < δ` has a
unique lift `w` with `d(z, w) < η/3`, depending continuously on `(z, y)`.
For `T ∼_R S` and `T′ ∈ P(T)`, let `w(t)` be the lift of `S − t` near
`(T − t, T′ − t)`; then `w(t) + t` is a continuous path in the finite set
`π₁⁻¹(S)`, hence a constant `(S, S′)`, and `d(T′ − t, S′ − t) → 0`. By (E1)
and (Z4) `h(S′) = h(T′)`, so (R3) makes `T′`, `S′` agree on a half-line.
Uniqueness is Lemma C(b); the construction from `S` back to `T` is the
inverse. ∎

*Theorem NC′.* Assume `π₁` is a covering and, for a contradiction, that `𝒦`
is a tree. (a) `P(T) ⊂ F₀` for `T ∈ F₀`, by (Z4). (b) The members of `P(T)`
lie in pairwise distinct `∼_R`-classes and pairwise distinct `∼_L`-classes
(Lemma C(b)), and none lies in `[T]_R` or `[T]_L` (asymptotic tilings share
tiles, which (Z2) at `n = 0` forbids). (c) If `T ∼_R S` in `F₀`, then `P(T)`
and `P(S)` meet the same `∼_R`-classes (Lemma L); likewise for `∼_L`.
(d) The vertex-type members lie in `𝒦` (Step 0, `ER` connected), and so do
both members of the root pair `(T₀, T₀′)` of (Z3) (common vertex at `0`,
(R4)). (e) A partner lies in `𝒦` iff its `R`-class does iff its `L`-class
does; so for `T = (A, D) ∈ E(𝒦)`, `P(T) ∩ E(𝒦)` is a perfect matching
between `ρ(A)` (the `R`-classes of `P(T)` in `𝒦`) and `λ(D)` (the
`L`-classes), and by (c) `ρ` depends only on `A`, `λ` only on `D`. (f)
`|P(T) ∩ E(𝒦)|` is constant along shared classes, hence on `𝒦`, and at least
1 because `T₀′ ∈ P(T₀)`. (g) *Selection.* Pick an `R`-vertex `A₀` and
`ψ(A₀) ∈ ρ(A₀)`; traverse the tree; crossing an edge `T = (A, D)` from an
assigned endpoint, take the unique `T′ ∈ P(T) ∩ E(𝒦)` whose class there is
the assigned image and give the other endpoint the other class of `T′`. Each
vertex is assigned once, edges go to edges, sides are preserved, and no
vertex is fixed by (b). (h) *Tree lemma.* For a side-preserving
homomorphism `ψ` of a finite tree, the images `ψⁿ(V)` are decreasing vertex
sets of subtrees and stabilise at `V_∞` with `ψ(V_∞) = V_∞`, where `ψ` is an
automorphism; by Jordan's theorem it fixes the centre, a vertex or an edge,
and a swapped central edge would exchange the sides, so a vertex is fixed.
This contradicts (g). ∎

*Corollary NC.* Under (NM_V) the `R`-class of `T_(b,a)` is
`C_a = {T_(c,a)}` and its `L`-class is `D_b`, so `𝒦 = ER`, with no
multi-edges. With `dim H¹ = 3`, `ER` is a tree, so `π₁` is not a covering
(NC′), hence locally injective at no point (Lemma C(d)), and some tiling has
two distinct partners that agree on a half-line (Lemma C(c)). (NM_V) follows
from injectivity of `g` and `g_R`: a right-asymptotic member `S` of `F₀`
branches at `0` (Lemma A), so it has a vertex at `0` and the tile `a` on
`[0, ℓ_a]`, i.e. `S = T_(c,a)`; the left case is the mirror. No step uses the
determinant. ∎

*Proposition F.* The norm map `N(h)(T) = ∏_{z ∈ π₁⁻¹T} h(z)` is continuous
(local sections). The lifts of `T − t` are the `z_i − t`, so
`W_Ω(Nh) = k·W_Z(h)` (unique ergodicity of `Z`, §3.4(iv)). The
tile-indicator map `h_B`, winding once per `B`-tile, has `W_Z(h_B) = x_B`. By
Lemma 9″ every class of `Ȟ¹(Ω; ℤ)` is `[f_λ]` with `λ ∈ E` and
`W(f_λ) = λ`, so `W_Ω(Ȟ¹(Ω; ℤ)) = E`. Hence `k·x_B ∈ E`, and the same
argument applies to every collared-patch class. ∎

*Corollary P.* Write `x_B = u_B·r` with `u_B ∈ ℚ³`. The letter frequencies of
the top track give `Σ_B p_B x_B = r`; the entries of `r` are ℚ-independent,
so `Σ_B p_B u_Bᵀ = I`. If `JZ = Z`, no bigon is `J`-fixed, `x_{JB} = x_B`
(unique ergodicity) and `p_{JB} = p_B` (balance); splitting `C₀ = C₁ ⊔ JC₁`
gives `Σ_{C₁} p_B u_Bᵀ = I/2`. Multiplying by `k`, each `k·u_B` lies in
`⋃(Mᵀ)^{−l}ℤ³ ⊂ ℤ[1/det M]³`, so `k/2 ∈ ℤ[1/det M]`. For an integer `k`
this holds exactly when `k` is even or `det M` is even. `k ≥ 2` by Fork (1);
B15 Thm 4(1) gives a fibre of `h` with exactly `cr` points, and `P(T)` lies
in it minus `T`, so `k ≤ cr − 1`. ∎

### 4.2 Where the module differs from the note

None of these contradicts the note; the first two are small gaps in its
wording.

1. Lemma 4(1) needs `k ≥ 1` in its forward direction, which the note leaves
   implicit: at `k = 0`, `σ⁰(j) = j` forces `P = Q = ε` and
   `(M⁰ − I)v = 0 = p(ε)`, so "then `P` and `Q` are nonempty" is false. In
   the converse `k ≥ 1` follows from `P ≠ []`.
2. The note's step "`ℓ·p(P) = (β^k − 1)ℓ·v > 0`" uses Lemma 1(1) silently
   (`v ≠ 0 ⇒ ℓ·v ≠ 0`). Lean makes it the explicit hypothesis `hzero`, and
   `carrier_periodic_not_interior` shows that it cannot be dropped. The
   note's first sentence holds without it (`periodic_iff_factorisation`).
3. Lemma 1(1) holds on any finite alphabet and for any nonzero real left
   eigen-row, not only the positive Perron row.
4. Lemma 1(3) in matrix form needs only one root `r` of `χ_M` with
   `r^k ≠ 1`; the spectral form is proved over `ℂ` from a root of modulus
   `> 1`.
5. "`v := (M^k − I)^{−1}p(P) ∈ ℤ³`" is encoded as the existence of an integer
   `v` with `(M^k − I)v = p(P)`, unique by Lemma 1(3).
6. Lemma 4(2) is for one fixed functional `L`; one direction needs no
   `m ≥ 1`.
7. Lemma 4(3) is proved twice: by the edge reflection of
   `PscVerif.GeometricFRank` (no `β > 1`), and by the note's correspondence
   of addresses (`β > 1`); both use `hzero`.

*Not formalised:* Lemma 5 of the note (the identifications with
Minervino–Thuswaldner and with the leftmost-chain note); that `01/12/021` is
PIP3; (F) for any specimen other than those already on main; anything about
Theorems FC2, P, FC3, N, Fork beyond supplying `hzero`. Lemma 1(2) is
`PscVerif.GeometricFPisot` and is not repeated.
