## 1. Headline

The mathematics added since 2026-09-08 is internally coherent as far as this audit can verify and is generally labelled with appropriate guardrails. The main weakness is no longer an obvious false lemma; it is **program shape**.

The repository has accumulated a long chain of increasingly fine necessary-condition sieves for a hypothetical finite closed nonproductive SCC. Those reductions are useful and mostly uniform once such an SCC is given, but the recent `|C|=3` layers are calibration rather than a plausible complete proof strategy. The next main theorem target should therefore be **uniform in `|C|`** and should use information that the existing algebraic sieves do not: the prefix-difference return structure and recognizability/supertile alignment.

The second weakness is record drift. `README.md`, `tla/Ledger.tla`, `docs/conjecture-ledger.md`, `docs/proof-ladder.md`, and `docs/verification-architecture.md` do not yet describe the current C4 reduction stack accurately.

## 2. Scope and notation

`FCS` means that a finite closed nonproductive recurrent noncoincident SCC `C` of the balanced-pair graph is already given.

This distinction matters:

- **G1 is used to pass from a global nonproductive region to such a finite sink SCC.**
- Once an FCS is given, many subsequent structural lemmas do not separately assume global BPA finiteness.
- The global endpoint synchronization theorem does not require Pisot or G1 at all.

So it is too broad to say that all recent work is "inside the G1 box." The accurate statement is:

> The current proof route from failure of C1 to a finite obstruction uses G1 at the sink-SCC extraction step; most C4 structure is then conditional on the resulting finite closed SCC rather than on global BPA finiteness itself.

## 5. Current conditional proof architecture

The machine-checked bridge remains

```text
G1 and C1  =>  PDS
```

in the standing alphabet-3 PIP regime.

Under G1, the current **sufficiency** chain is

```text
C4  =>  C3-local  =>  C2  =>  C1.
```

These arrows are proof-dependency/sufficiency arrows. They must **not** be encoded or described as converses. In particular, a dependency ledger may say that the present proof of C1 passes through C4; it must not assert the mathematical implication `C1 => C4` or an equivalence.

A hypothetical FCS witnessing failure of the current C4 target must simultaneously satisfy, among other constraints:

- both endpoint maps are in nonsynchronizing types C-G;
- endpoint-signature dynamics live in at most 1/3/9 projected phases;
- `P N = M P`, rank `P=3`, and `rho(N)=beta`;
- `S=A-B` with `rho(S)<=beta`;
- the first nonzero scattered-subword defect gives a signed representation quotient;
- degree-2 components satisfy the parity size sieve;
- degree-3 components are forced into the determinant/centralizer sector;
- ordered child words satisfy the mid-area identity.

Exact finite calibration over the established 4,554 alphabet-3 PIP substitutions remains evidence only: all BPA builds terminate below the cap, every observed sink is productive, 385,902 reachable noncoincident states have first defect degree 2, 24 have degree 3, and none has degree >=4.

## 6. G1 and the balanced-pair literature: corrected statement

The original audit correctly flagged G1 as strategically important, but its wording was too fast.

Akiyama, Barge, Berthe, Lee, and Siegel, *On the Pisot Substitution Conjecture* (2015), Theorem 5.3, states for an irreducible Pisot substitution that the symbolic system has pure discrete spectrum **iff** the balanced-pair algorithm terminates with coincidence; it further states that it suffices to start from a seed of the form `(ij,ji)`. Sirvent-Solomyak (2002) is part of the underlying balanced-pair/overlap literature.

This strongly suggests that PDS implies finiteness of the relevant balanced-pair factor set. However, the repository should not yet record the bare theorem

```text
PDS => G1
```

until it proves a short **BPA definition bridge**:

1. identify precisely the literature's seed-generated irreducible-factor closure;
2. identify this repository's normalized all-seed graph `B_sigma`;
3. prove that termination from one literature seed in the irreducible Pisot setting gives finiteness of the repository graph, or state the exact additional reachability argument required.

Once that bridge is written, the G1 relationship can be promoted from literature-alignment note to a repository theorem. Until then, say:

> Literature gives PDS iff termination-with-coincidence for the standard balanced-pair algorithm; applicability to this repository's exact all-seed graph is pending a definition/reachability bridge.

This is a bookkeeping/theorem-identification gap, but it is important because it changes whether `G1 and C1` is merely a sufficient route or essentially a reformulation of the target.

## 7. Sieve saturation and strategic pivot

The recent three-state work is useful calibration: it shows exactly which invariants distinguish increasingly realistic golden negatives. It should now stop as a main proof spine.

The reason is structural. For a fixed finite BPA, one can always decide the existence of a counterexample component by building the graph. A new finite sieve has proof value only when accompanied by a **uniform completeness statement** over substitutions or SCC sizes.

The two strongest theorem-grade ingredients not yet applied to the actual factorization obstruction are:

### 7.1 Prefix-difference return structure plus Pisot contraction

For a balanced pair `T=(u,v)`, define

```text
D_T(k) = Parikh(u[:k]) - Parikh(v[:k]).
```

Irreducibility means `D_T(k) != 0` at every interior cut. Under substitution, image ordering expands this into a piecewise lattice walk; its returns to zero are exactly the balanced child boundaries.

For a finite closed SCC, the state lengths are bounded while iterates grow at rate `beta`, so returns in the inflated pair occur with bounded block lengths. The next uniform theorem should couple this dense return structure to contraction in the stable Pisot directions.

### 7.2 Recognizability / supertile-boundary alignment

In the gauge-trivial orientation case, the SCC gives two distinct word morphisms with the same Parikh data and a common derived substitution. Existing notes do not prove that balanced-child cuts align with `sigma`-supertile boundaries. Mossé-style recognizability is the natural tool for upgrading repeated/recurrent cut patterns into such alignment or a contradiction.

The next proof target should therefore be an **alignment-or-return-density lemma**, not another `|C|=3` arithmetic sieve.
