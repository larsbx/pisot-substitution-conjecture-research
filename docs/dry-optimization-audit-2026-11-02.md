# DRY / optimization refactor audit — 2026-11-02

**Scope:** `main@cfc31d1` (after PR #450). Read-only audit of `kernel/`, `oracles/python/`,
`reference/psc_research/`, `tools/`, `tests/`, `.github/workflows/`. Vendored packages
(`vendored.toml`) are out of scope by policy.

**Status:** engineering audit. It changes no claim status, source file or evidence packet.
LOC estimates are approximate (`wc`/`diff` counts after label normalisation); none of the
proposed changes has been implemented or benchmarked here.

## 0. The governing constraint: live source pins

Most duplicated code is **byte-frozen by CI**, so the refactor surface is much smaller than
the duplication surface.

| Live checker | Pinned set | Effect |
| --- | --- | --- |
| `tools/check_research_source_manifest.py:34-45` over `evidence/class-a-boundary-*/source-sha256.txt` (≈20 workflows, e.g. `class-a-boundary-d5.yml`) | all 125 `class_a_boundary*` kernel/psc/test files, 41 oracles, 19 workflows, … (437 live-checked paths over 38 manifests) | any non-whitelisted byte change ⇒ `changed mathematical source` |
| `tools/check_class_c_below_three_integration.py:51-53`, `check_class_c_below_three_imports.py:49` over `evidence/class-c-below-three-2026-10-29/provenance.json` | ≈45 kernel files incl. `psc/{bpa,histogram,pisot,words,exact,overlap_*,coincidence_formula,symbolic_line}.mojo` | same |
| revision-scoped packets (`class-a-finite-certificates-2026-11-02`, `issue139-*`, `class-a-carrier-closure-2026-10-22`, …) | ray/regime tables, `kernel/run_tests.sh`, `_probe_d.mojo` | checked at recorded revision only ⇒ **editable** |

Re-pinning a live manifest overwrites an archived record (AGENTS.md "refuse to overwrite").
Hence a decision is required before any frozen-family refactor:

- **(a)** extend `check_research_source_manifest.py` with a revision-scoped mode
  (`git show <rev>:path` against the pin, as the finite-certificates packet already does), so
  HEAD may move while the archive stays replayable; *governance change, needs explicit sign-off*;
- **(b)** freeze existing modules; route only new work through shared modules (duplication
  stays, stops growing).

## 3. Recommended order

1. **A1, A2** (runtime; unpinned infra). Measure before/after on the full `run_tests.sh`.
2. **A6, A7, A9, A10, A12** (low-risk kernel DRY), each with a byte-identical census-output
   regression per AGENTS rule 10.
3. **A3–A5** (ray tables + `--check` gate), **A8, A13** (histogram/assert fail-closed fixes).
4. **A15** archive moves with ledger lines; **A14** shared oracle library for new work.
5. **B3, B4** as new modules beside the frozen family; adopt them for every new label so
   B1's duplication stops growing (route (b)).
6. Decide (a) vs (b); only under (a) attempt B1, B2, B5, B6.
7. **A16** ports, scheduled with the C4 porting order.
