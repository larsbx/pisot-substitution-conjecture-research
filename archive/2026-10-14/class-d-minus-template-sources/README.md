# Frozen sources for the minus-boundary packet

These are the exact source bytes pinned by
`evidence/class-d-minus-template-2026-10-14/source-digests.json`, recovered
from commit `38b87af7697c07641995e2ffe3be2b4cef275ded` before extending the
shared engine to the plus branch. The original evidence packet is unchanged.

`sources.json.gz` is deterministic gzip-compressed JSON with `source_commit`
and a `sources` map from repository-relative paths to UTF-8 source contents.
The regression checks every archived source against the existing sealed
SHA-256 digest. This works in shallow CI checkouts without fetching history.
The snapshot is historical evidence, not a second live implementation.
Current implementations are still replayed against the archived graph.
